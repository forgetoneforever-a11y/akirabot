AKIRA Clicker

Telegram WebApp-кликер с прокачкой, уровнями, ежедневными наградами, заданиями и таблицей лидеров.

Возможности

- Кликер и накопление монет.
- Улучшения для увеличения дохода.
- Система опыта и уровней.
- Ежедневные награды.
- Задания и получение наград.
- Мини-игра.
- Таблица лидеров.
- PostgreSQL для хранения данных.
- Авторизация через Telegram WebApp.

Требования

- Node.js.
- PostgreSQL.
- Telegram-бот, созданный через @BotFather.
- Аккаунт Render для публикации.

Локальный запуск

1. Склонируй репозиторий:
   
   git clone URL_ТВОЕГО_РЕПОЗИТОРИЯ
cd ИМЯ_РЕПОЗИТОРИЯ

2. Установи зависимости:
   
   npm install

3. Создай файл ".env" на основе ".env.example".

4. Укажи переменные окружения:
   
   NODE_ENV=development
PORT=3000
BOT_TOKEN=ТОКЕН_ТВОЕГО_БОТА
DATABASE_URL=СТРОКА_ПОДКЛЮЧЕНИЯ_POSTGRESQL

5. Запусти сервер:
   
   npm start

6. Открой в браузере "http://localhost:3000".

Публикация на Render

1. Загрузи проект в GitHub.

2. В Render выбери создание нового Web Service.

3. Подключи репозиторий.

4. Укажи команду сборки:
   
   npm install

5. Укажи команду запуска:
   
   npm start

6. Создай PostgreSQL-базу и добавь "DATABASE_URL" в Environment.

7. Добавь токен бота в Environment под именем, которое использует "server.js".

8. После успешного деплоя проверь адрес "/health".

Подключение к Telegram

1. Открой @BotFather.
2. Настрой Web App для своего бота.
3. Укажи URL опубликованного приложения на Render.
4. Открой приложение через кнопку бота в Telegram.

Безопасность

- Не публикуй ".env" и реальные токены.
- Не добавляй секреты в GitHub.
- Для работы с Telegram WebApp сервер должен проверять подпись "initData".
- Для production используй HTTPS.

Примечание

Перед публикацией проверь, что названия переменных окружения, маршруты API и HTML-файлы соответствуют текущему коду проекта.
