# AKIRA! — Telegram Cookie Clicker

Стартовый проект: Telegram-бот + Mini App + Node.js/Express + PostgreSQL, подготовленный для Render.

## Что уже есть
- Печенька с анимацией нажатия и всплывающим `+монеты`.
- Сила клика, автокликер, множитель.
- Рейтинг за неделю, месяц и год.
- Ежедневная награда и серия входов.
- Профиль, баланс, общий заработок и уровень.
- Серверное начисление монет и PostgreSQL.
- Проверка Telegram `initData` на сервере.

## Запуск на Render
1. Создай бота через `@BotFather` и скопируй токен. Не отправляй токен в чат и не добавляй его в GitHub.
2. Загрузи содержимое этой папки в свой GitHub-репозиторий.
3. На Render выбери **New → Blueprint** и подключи репозиторий с `render.yaml`.
4. В переменных сервиса задай `BOT_TOKEN` и `WEBAPP_URL`. В `WEBAPP_URL` укажи HTTPS-адрес веб-сервиса Render, например `https://имя-сервиса.onrender.com`.
5. `DATABASE_URL` должен быть **Internal Database URL** созданной базы Render. Если Blueprint не связал её автоматически, добавь эту переменную вручную.
6. Дождись успешного деплоя. Открой адрес сервиса в браузере — `/health` должен вернуть `{"ok":true,"app":"AKIRA"}`.
7. В Telegram найди своего бота и отправь `/start`, затем нажми **🍪 Играть в AKIRA**.

## Локальная проверка
- Установи Node.js 20+.
- Скопируй `.env.example` в `.env` и заполни переменные.
- Установи зависимости: `npm install`.
- Запусти: `npm start`.

Для проверки Mini App в Telegram нужны действительные `initData`, публичный HTTPS URL и токен бота.

## Важно
- Это игровой баланс, не реальные деньги.
- Перед публичным запуском рекомендуется добавить лимиты частоты кликов и автоматических начислений, обработку сбоев и резервное копирование БД.
- Бесплатные сервисы Render могут засыпать при простое; первый запрос после простоя иногда занимает больше времени.
